About Rookery

Your backlog should not wait for a free afternoon.

Every team has a list of issues that matter but never come first: the small fix, the missing test, the cleanup everyone agrees on. They sit for months because the people who could do them are busy with the work that does come first.

Rookery exists to move that list. You label an issue at the end of the day, and in the morning there is a plan to read or a pull request to review. The work keeps going while you are away. The decisions wait for you.

What we believe

An agent you can trust is one you can steer

People decide, agents do

Rookery asks before it starts and never merges. You approve the plan, you review the result, and the last word on your code is always yours.

No surprises

You see the plan before any code is written, and every step is visible on the issue itself. If something goes wrong, you hear about it there, in plain words.

Fits how you already work

No new tool to learn and no new place to look. Issues, comments, labels and pull requests on GitHub are the whole interface.

Predictable cost

Daily limits per repository and a steady cost per task, so a big issue never turns into a big bill you did not expect.
